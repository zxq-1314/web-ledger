📒 网页版记账本 (Web Ledger)



一个基于 Python Flask开发的轻量级记账 Web 应用。支持账目的增、删、改、查，数据持久化存储于本地文件，界面采用 Bootstrap\*美化，响应式且干净简洁。



> 这是我在大一暑假完成的第一个全栈练手项目，完整实现了 Web 应用的核心 CRUD 操作。

✨ 功能特性



&#x20;➕ 添加账目 – 通过表单录入名称、金额，系统自动记录当前时间

&#x20;📋 查看列表 – 以表格形式展示所有账目，支持斑马纹和悬停高亮

&#x20;✏️ 编辑账目 – 点击编辑按钮，回填原有数据，修改后自动更新时间戳

&#x20;🗑️ 删除账目 – 一键删除，并有确认弹窗防止误操作

&#x20;💰 自动汇总 – 实时计算并显示总支出（保留两位小数）

&#x20;💾 数据持久化 – 数据保存在本地 `data.txt` 文件中，重启程序不丢失

&#x20;🎨 美观界面 – 使用 Bootstrap 5 构建，卡片式布局，视觉友好

⚙️ 如何运行



1. 确保已安装 Python 3.8+（\[下载地址](https://python.org)）



2. 安装 Flask 依赖（在终端执行）：

&#x20;  ```bash

&#x20;  pip install flask



3\.克隆或下载本项目，进入项目目录：

&#x20;  cd web-ledger



4\.启动应用：

&#x20;  python web\_ledger.py



5\.打开浏览器，访问 http://127.0.0.1:5000 即可使用。



\---



🖥️ 使用指南



查看所有账目：访问首页即显示完整列表及总计金额。



添加新账目：点击“➕ 添加新账目”按钮，填写名称和金额，提交后自动返回首页。



编辑账目：点击任意记录旁的“✏️ 编辑”按钮，修改内容后保存，日期将自动更新为“编辑于 ...”。



删除账目：点击“🗑️ 删除”按钮，在确认弹窗中选择“确定”即可移除该条记录。
